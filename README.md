# Safe Calculator

A small Python calculator project implemented in `calculator.py`.

## Requirements
- Python 3.8 or later

## Getting started
```bash
git clone https://github.com/dperry713/safe_calculator.git
cd safe_calculator
python calculator.py
```

Follow any terminal prompts provided by the script.

## Project structure
- `calculator.py` — calculator implementation.

## Development
Validate user input, handle invalid operations and division by zero, and do not evaluate arbitrary user-provided expressions. Add tests for normal inputs and error conditions.
